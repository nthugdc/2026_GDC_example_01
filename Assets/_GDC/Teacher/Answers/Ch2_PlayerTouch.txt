三個 Trigger 事件的差別
------------------------
    OnTriggerEnter2D   剛碰到的那一幀，呼叫「一次」
    OnTriggerStay2D    只要還重疊著，「每一幀」都呼叫
    OnTriggerExit2D    離開的那一幀，呼叫「一次」

    播放時看 Inspector 上的 Pad Seconds：踩上去之後它會一直往上跳，
    這就是 Stay 每幀都在執行的證據。Enter 只會在踩上去那一瞬間跑一次。

    ⚠ Stay 每幀都跑，所以裡面不要放很重的運算，也不要在裡面加分
      （會變成「站著不動就一直得分」）。要計時就像上面那樣累加 Time.deltaTime。

    ⚠ 剛體休眠會讓 Stay 停止觸發
      Rigidbody 2D 靜止超過 Physics2D.timeToSleep（預設 0.5 秒）會自動休眠，
      休眠中的剛體不再發出 OnTriggerStay2D。症狀就是「站著不動計時卡在 0.5 秒，
      稍微走動又開始跳」。
      本教材已經把玩家的 Sleeping Mode 設成 Never Sleep 避開這個問題。
      想示範的話，把它改回 Start Awake 再站上感應板，一看就懂。


other 是什麼？為什麼可以改到對方的顏色？
-----------------------------------------
    other 的型別是 Collider2D，是「碰到我的那個東西身上的碰撞器元件」，
    它是一個元件，不是物件本身。

    在 Unity 裡，拿到任何一個元件就能找到它所屬的物件與其他元件：
        other.gameObject              → 那個東西本身
        other.GetComponent<T>()       → 從它身上再拿出別的元件

    所以 other.GetComponent<SpriteRenderer>().color = ... 的意思是
    「從碰到我的那個碰撞器，找到它所屬物件的繪製元件，然後改它的顏色」。


Destroy 的效果
--------------
    Destroy(other.gameObject)   整個物件從場景移除，會直接消失 ← 金幣要用這個
    Destroy(other)              只移除那個碰撞器元件，物件還在，只是不再會被碰到
    Destroy(物件, 3f)            3 秒後才刪除

    刪除不是立刻發生，而是在這一幀結束後才真的執行。


為什麼要用 CompareTag 而不是 other.tag == "Coin"？
--------------------------------------------------
1. CompareTag 比較快（不會產生垃圾記憶體）。
2. 如果 Tag 名稱拼錯，CompareTag 會直接丟出錯誤告訴你「這個 Tag 不存在」；
   用 == 比較的話只會安靜地永遠不成立，你會找很久。


常見問題
--------
Q: 出現「Tag: Coin is not defined」？
A: 這個 Tag 還沒建立。Edit > Project Settings > Tags and Layers > Tags 加上去。
   （本教材已經預先幫你建好 Coin / Spike / Goal，出現這個錯誤通常是拼錯字。）

Q: 碰到金幣沒反應？
A: 三件事要檢查：
   1. 金幣的 Tag 有沒有指派成 Coin（Inspector 最上方）
   2. 金幣的 Collider 有沒有勾 Is Trigger
   3. 玩家身上有沒有 Rigidbody 2D（Trigger 事件需要至少一邊有剛體）


加分題
------
自己新增一個 Bonus tag，複製一枚金幣改成 Bonus 並換個顏色，
然後在腳本裡加一段「碰到 Bonus 加 5 分」。
